Explicit-ruby engine probe

An explicit-ruby expression only shapes if the whole START BASE OPEN RUBY CLOSE run reaches GSUB in one shaping call. Engines that itemise a text node into script runs first (Blink does) may split it at the Han↔Kana boundary, and then no rule can match.

The test is the advance width: the delimiters and the ruby glyphs are zero-advance, so a working expression measures exactly its base length in ems. A split one measures its full character count. That is a binary, rasteriser-independent signal.
