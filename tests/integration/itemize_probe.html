Shaping-run itemization probe

Each case is a character sequence the probe font carries one GSUB rule for. The rule replaces the sequence's first glyph with a zero-advance blank, so the text measures one em narrower if and only if the whole sequence reached GSUB in a single shaping run.

Measured through DOM layout, not canvas: the two disagree in Chrome. Every character is in the probe font, so a split can never be font fallback.
